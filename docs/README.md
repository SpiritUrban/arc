# Документація ARC

ARC — Node.js/TypeScript-фреймворк, у якому застосунок описується графом операцій та ресурсів. Операція містить контракт і бізнес-логіку, ресурси надають їй залежності, а HTTP, RPC та черга викликають операцію через спільний executor.

Цей посібник описує **поточну реалізацію** в `framework/`. Початкове обговорення ідей збережене в [`doc.md`](../doc.md); воно містить також можливості, які ще не реалізовані.

| [Початок роботи](getting-started.md)   | Встановлення, запуск, CLI, структура репозиторію                           |
| [Архітектура](architecture.md)         | Граф, компіляція, execution plan, scopes, lifecycle та telemetry           |
| [Як писати код](writing-code.md)       | Контракти, операції, ресурси, помилки, модулі та завершений приклад        |

Рекомендований порядок першого знайомства: початок роботи → як писати код → тести. Архітектура пояснює внутрішню модель, довідник допомагає знайти точний виклик API.

## Приклади, які можна запустити

- [`src/app.ts`](../src/app.ts) — основний застосунок: користувачі та замовлення.
- [`examples/tasks.ts`](examples/tasks.ts) — самодостатній приклад feature-модуля завдань.
- [`examples/tasks.test.ts`](examples/tasks.test.ts) — тести прикладу без підняття HTTP-сервера.

З кореня репозиторію:

```sh
npm run build
ARC_APP=docs/examples/tasks.ts npx arc stand
node --conditions=arc-source --import tsx --test docs/examples/tasks.test.ts
```

Усі приклади використовують ESM та імпорти з `@arc/framework`. Для відносних імпортів TypeScript-файлів у цьому проєкті вказується розширення `.ts`.
