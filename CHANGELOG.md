# Журнал змін ARC

Тут записуємо зміни публічного API, поведінки, інструментів і навчальних прикладів ARC. Усі версії `0.x` належать до етапу активної розробки. Якщо зміна потребує дій у наявному застосунку, додаємо інструкцію з оновлення до відповідної версії.

## У розробці

### Сервер
- `operation(contract, implementation)` пов’язує серверний код зі спільним контрактом. TypeScript виводить типи входу, результату, помилок і ресурсів.
- `http.get/post/put/patch/delete(path, contract, implementation)` створює маршрут та операцію в одному виклику. Запис із готовою операцією також підтримується.
- Експериментальний `@handles` позначає публічні статичні методи. `handlerModule` явно збирає їх в ARC-модуль. У Workspace цей варіант показано на GET замовлень поруч із прямим POST-маршрутом.

### Браузер і Fullstack
- `remoteForm` пов’язує текстові поля, серверний контракт і дію форми. Після успіху відновлює початкові значення полів, які не змінювалися під час запиту, виконує `onSuccess` та оновлює ресурси з `refresh`. Додано `textField`, `integerField` і виведення ID дії з контракту.
- `remoteApi` задає спільні заголовки й реактивні джерела для `query` і `form`. У Workspace клієнт замовлень використовує вибраного користувача для обох запитів.
- Реактивний стан, похідне значення або `project(source, format)` можна вставити прямо в JSX як текст. ARC оновлює текстовий вузол і показує його джерело в графі. `project` також працює з односторонніми директивами прив’язки.

- `each(source, { key, render })` додає списки з ключами без обгорток у JSX. ARC зберігає незмінні DOM-рядки й показує залежність від джерела в Stand.

### Stand та приклади
- Stand розкладає напрямлений граф через Dagre. Стрілки показують напрямок, вибір вузла підсвічує його вхідні та вихідні зв’язки, масштабування допомагає переглянути весь граф.
- Кожен запущений CLI застосунок отримує власну тимчасову браузерну збірку. Окрема команда `arc build` записує результат у `.arc/web`.
- Workspace перенесено до `examples/workspace/`. Сторінки використовують спільний модуль вибору користувача, а серверні функції лежать у `server.ts` відповідного модуля.
- Fullstack Tasks показує `remoteForm`, спільні контракти та `project`. Counter показує локальну реактивність і форматування в прив’язці.

## 0.5.0

- Додано TSX-директиви `bind:text`, `bind:value`, `bind:disabled`, `bind:visible`, `bind:children` і `on:…`. ARC створює вузли прив’язок і ребра залежностей до mount. Їх видно у Stand, навіть коли у view немає явного списку `bindings`.
- `bind:value` створює вузли читання та вводу для текстового поля. `on:submit` скасовує стандартну навігацію та захищає дію від повторного надсилання під час виконання.
- Workspace, Web Counter і Fullstack Tasks переведено на короткі прив’язки. Оновлено посібники та урок про реактивний DOM.

Для переходу приберіть список `view.bindings` і перенесіть звичайні прив’язки в директиви TSX. У цьому режимі функція шаблону виконується під час оголошення view. Наявний режим з явним списком і `setup` підтримується. [Посібник про TSX](docs/web/views.md)

## 0.4.0

### Фреймворк

- ARC Web отримав TSX-шаблони через `view({ template, bindings })` і JSX runtime `@arc/framework/web`. У шаблоні `bind={…}` підключає реактивні значення та події до HTML-елементів. Шаблон виконується один раз на mount.
- Binding `children` оновлює вміст окремого контейнера з TSX. Workspace використовує його для списку користувачів і рядків таблиці замовлень. Текст із даних вставляється текстовими вузлами.

### Приклади й документація

- Workspace, Web Counter і Fullstack Tasks переведено на TSX. Додано посібник, оновлено урок про реактивний DOM і приклад на головній сторінці ARC.
- Для Workspace, Counter, Tasks і сайту документації додано окремі іменовані команди запуску.
- Офіційний сайт з документацією та уроками публікується на GitHub Pages через GitHub Actions.

Для переходу на TSX задайте `jsx: "react-jsx"` і `jsxImportSource: "@arc/framework/web"` у TypeScript. Наявні views із `setup` можна переносити поступово. [Посібник про TSX](docs/web/views.md)

## 0.3.0

- ARC Web додав reactive state, derive, actions, resources і DOM bindings.
- ARC Fullstack об’єднав браузерні й серверні вузли в IR v3. Додано спільні контракти, явні remote boundaries, браузерну збірку й наскрізні traces у Stand.
- Пакет отримав окремі точки входу для core, server, web і fullstack. У репозиторії з’явилися приклади Counter, Tasks і Workspace.

## 0.2.0

- Розділено компіляцію графа й запуск ресурсів. Додано явні вкладені виклики та scheduler, який запускає вузли, щойно готові їхні залежності.
- IR v2 описав транспортні вузли, ефекти та їхні зв’язки. Stand отримав активність через SSE, збережені сценарії тестування й незалежні метрики.
