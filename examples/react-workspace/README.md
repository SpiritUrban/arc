# React Workspace

Окремий приклад для порівняння з ARC Workspace. React Router відповідає за браузерні маршрути, Vite збирає клієнтський код, Node обслуговує API. Спільні стилі беруться з ARC Workspace в цьому репозиторії. Сценарії та початкові дані описані в [таблиці паритету](../../docs/workspace-parity.md).

## Запуск

З цього каталогу на Node.js 22.18 або новішій версії:

```sh
npm ci
npm run dev
```

Dev відкривається на `http://127.0.0.1:5173`. Vite пересилає виклики `/api/` до локального Node API.

```sh
npm run build
npm start
```

Зібраний застосунок і API доступні на `http://127.0.0.1:4325`. Для обох режимів порт можна змінити через `PORT`.

Каркас відкриває `/`, `/orders` і `/orders/:id`. `GET /api/health` повертає `{ "ok": true }`. Панель користувачів дозволяє знайти, вибрати, створити та відредагувати профіль. `/api/users` обслуговує список і створення, `/api/users/:id` — читання та редагування. Дані профілів скидаються після перезапуску Node. Сценарії замовлень заплановані в наступних ітераціях.
