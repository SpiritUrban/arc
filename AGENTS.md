# Робота над API ARC

- Починай зі сценарію в основному прикладі `examples/workspace`. Повторюваний код у різних компонентах підказує, який шаблон варто підтримати у фреймворці.
- Описуй сталі правила, варіанти й зв’язки даних у контракті або конфігурації, коли їх використовують кілька частин застосунку. Компонент має переважно відображати дані, визначати текст і підключати дії.
- Оцінюй спрощення за читабельністю коду застосунку, кількістю повторених рішень і тим, наскільки послідовно API структурує схожі сценарії. Технічна перевага має проявлятися в реальному сценарії.
- Застосовуй зміни API одразу в Workspace і перевіряй збірку та поведінку прикладу.
